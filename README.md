# 🎧 Spotify Clone

A frontend clone of Spotify built using **React.js**, **HTML**, **CSS**, and **JavaScript**. This project replicates core features of the Spotify UI including song playback, album browsing, and more!

---

## 🚀 Features

- 🎵 **Play Songs**: Stream and control audio playback.
- 💿 **Browse Albums**: Navigate through a collection of albums.
- 🔍 **Responsive Design**: Fully responsive layout for all devices.
- ⚡ **Fast UI**: Smooth transitions and intuitive user experience.

---

## 🛠 Tech Stack

- **React.js** – JavaScript library for building user interfaces.
- **HTML5** – Markup language for structuring the app.
- **CSS3** – For styling and layout.
- **JavaScript** – Logic for playback and interactivity.
